Download the installer

Opens the newest release on GitHub. Under Assets, click Fragmio-…-setup.exe. Older versions

Install

  1. Run the downloaded file.
  2. If Windows says "Windows protected your PC", click More info → Run anyway. This shows because Fragmio is new, not because anything is wrong.
  3. Open Fragmio, start a new project and pick a video.

Needs

  • Windows 10 or 11, 64-bit
  • 8 GB memory or more
  • An NVIDIA graphics card makes exports faster, but isn't needed
Updating: in Fragmio, click Help → Check for updates. Install the new version over the old one; your projects and saved styles stay.
