## What it does

- **Mark clips** on one long video: set in and out points, name them, change speed.
- **Frame them** for vertical, square or wide: Fill, On background, Split and Trio layouts.
- **Style them**: text styles, frames and ready-made templates. Every clip has its own look, and you can copy a look to other clips.
- **Export them all at once** as MP4, up to 4K, using your graphics card when it can.

## Private by design

- Fragmio works **offline**. Your videos never leave your computer.
- It connects to the internet **only when you click Help → Check for updates**, and then it only reads one small version file. Nothing about you or your videos is sent.

## Download

Get the latest version from the **[Releases](../../releases)** page, or from the [Fragmio website](https://fragmio.vercel.app/download).

1. Download `Fragmio-Setup-x.y.z.exe`.
2. Run it. Windows may show "Windows protected your PC" because the app is new. Click **More info → Run anyway**.
3. Open Fragmio, pick a video and start marking clips.

**Needs:** Windows 10 or 11 (64-bit). A graphics card with NVIDIA NVENC makes exports faster, but it is not required.

## Updating

Use **Help → Check for updates** in the app. If a new version is out, it shows what's new and a Download button. Install it over the old one; your projects and saved styles stay.

## Feedback and problems

- Use **Help → Send feedback** or **Help → Report a problem** in the app, or the [feedback form](https://fragmio.vercel.app/feedback).
- When reporting a problem, attach the log file: **Help → Open log folder**.
